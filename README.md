# mobifreaks.github.io

Root of the Mobifreaks GitHub Pages domain. Each template serves its demo at `/<Repo>/`; this repo only redirects the root to [munawarahmed.com/mobifreaks](https://munawarahmed.com/mobifreaks).

The custom domain (`CNAME`) is added once the DNS record for `mobifreaks.munawarahmed.com` exists.
